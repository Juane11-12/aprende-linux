Este programa sirve para aprender comandos basicos desde la terminal

Con este programa echo en c++ te ayudara a no perderte en una terminal

EJECUCION LINUX:
Para ejecutar este programa simplemente necesitas ejecutarlo con "cd Descargas" y despues "./aprende-linux"

EJECUCION WINDOWS:
Para ejecutar este programa simplemente abre powershell y ejecuta ".\aprende-linux"
